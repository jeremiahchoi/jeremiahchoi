## Projects

**[SicilianZero](https://github.com/jeremiahchoi/sicilian)** · [live demo](https://jeremiahchoi.github.io/sicilian/)
A chess engine you can watch think. I trained a 1.7M-parameter network on grandmaster
games, exported it to ONNX, and built a React app that runs it entirely in the browser,
with no server. It shows why each move was chosen, replays classic games, and reports
accuracy on 677 held-out master positions (31.8% top-1 vs 7.1% for a random legal move).
